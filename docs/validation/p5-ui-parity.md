The Admin page exposes multi-game/preset/version registration, Controller-reported bindings and digests, content validation/publication and A2S state. At this checkpoint, the earlier P5C port-coverage implementation kept URI flags false. No ETA, Controller claim delay, Steam login timing, d2core internals or P50/P95 are exposed to players.
